# WoodNest

WoodNest is a modern and responsive landing page designed for a fictional sustainable living and interior design brand. The project focuses on clean UI design, smooth user interactions, and a seamless experience across desktop, tablet, and mobile devices.

## Features

- Responsive navigation bar
- Smooth scrolling navigation
- Scroll-based reveal animations
- Interactive service cards
- Testimonials section
- Contact form with JavaScript functionality
- Mobile-friendly hamburger menu
- Responsive design for all screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- Google Fonts
- Intersection Observer API

## What I Learned

Through this project, I improved my understanding of:

- Responsive web design
- Frontend development fundamentals
- JavaScript DOM manipulation
- Scroll-based animations
- Building user-friendly interfaces

## Project Objective

The goal of this project was to create a visually appealing and fully responsive landing page while strengthening frontend development skills through practical implementation.
